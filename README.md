# Nini Universe 홈페이지 (/home 미러)

https://nini-universe.github.io/home/ — 이 저장소 이름이 `home`이라 GitHub Pages가 이 경로로 올린다.

여러 앱의 스토어 등록 홈페이지 주소가 `/home`으로 잡혀 있어 유지한다.
원본은 `nini-universe/nini-universe.github.io` 저장소이며, 그쪽 `index.html`·`index-*.html`·`img/`를 그대로 복사해 두 벌로 운영한다.
루트 쪽을 바꾸면 여기도 같이 갱신할 것.

- `app-ads.txt` — AdMob은 도메인 루트(`https://nini-universe.github.io/app-ads.txt`)만 읽으므로 여기 파일은 참고용이다.
